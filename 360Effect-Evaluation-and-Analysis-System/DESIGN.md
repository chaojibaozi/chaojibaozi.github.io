# 360 搜索推广效果评估分析系统 · 界面设计方案（UI Design System）

> 设计者：UI Designer（像素君） ｜ 日期：2026-07-24 ｜ 形态：单文件离线 HTML（数据与引擎不变，仅重构视觉层）

## 一、设计目标与原则

- ** analyst-first（分析师优先）**：信息密度高、扫描效率高、动作直达。SEM 优化师的核心诉求是"快速定位问题→拿到可执行动作"，因此导航按分析模块组织，每个模块首屏即给结论与预警。
- **双主题自适应**：浅色（日间办公）/ 深色（长时盯盘与演示）一键切换，偏好持久化到本机。
- **品牌一致性**：采用 **360 品牌绿** 作为主强调色，AI 能力用独立紫罗兰色区分，避免与品牌绿混淆。
- **统一设计语言**：全部视觉元素由 design tokens 驱动，保证 95%+ 一致性；对比度满足 WCAG AA（正文 4.5:1，大字/粗体按钮 3:1）。

## 二、色彩系统（Design Tokens）

### 主色 · 360 品牌绿
| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--p` | `#0EA45C` | `#22C55E` | 主按钮/链接/激活态填充 |
| `--p-50` | `#E8F8F0` | `#102217` | 激活导航/浅底块 |
| `--p-700` | `#0A7C45` | `#5BE08A` | 主色文字（落在浅底） |

### 语义色（与品牌绿区分）
| 类型 | 浅色 | 深色 | 含义 |
|---|---|---|---|
| 成功 `--ok` | `#16A34A` | `#34D27E` | 稳定/扩量/正向 |
| 警告 `--warn` | `#E08A00` | `#F2AE3B` | 波动/降价/注意 |
| 危险 `--danger` | `#E5484D` | `#F26469` | 衰减/零转化/P0 |
| 信息 `--info` | `#2D7FF9` | `#5AA2FF` | 保持/提示 |
| AI `--ai` | `#6D4AFF` | `#8B6DFF` | 大模型解读入口 |

### 中性色
- 浅色：背景 `#F4F6F5` / 表面 `#FFFFFF` / 次级 `#F7F9F8` / 边框 `#E6EBE9` / 文字 `#15231D` / 次要 `#3D4B44` / 弱化 `#6B7A72`
- 深色：背景 `#0E1512` / 表面 `#16201B` / 次级 `#1B2722` / 边框 `#27332C` / 文字 `#E6EFEA` / 次要 `#C2CFC8` / 弱化 `#8A9A91`

## 三、字体与排版

- 字体族：`"PingFang SC","Microsoft YaHei",system-ui,…`（系统中文字体优先，无外部依赖）。
- 字号梯度：12 / 13 / 13.5 / 14 / 15.5 / 17 / 23(px)。行高 1.6。
- 数字使用 `tabular-nums` 等宽对齐（KPI、表格金额、转化数右对齐）。
- 模块标题 15.5px/700；页面标题 17px/700；正文 13–13.5px；弱化说明 12–12.5px。

## 四、间距 · 圆角 · 阴影 · 动效

- 间距基准 4px：`--s1…--s12` = 4/8/12/16/20/24/32/40/48。
- 圆角：控件 8px、卡片 12–16px、徽章/药丸 999px。
- 阴影：三层 `--sh-sm / --sh / --sh-md`，深色模式下用更深的 `rgba(0,0,0,.45)`。
- 动效：140ms 按钮反馈、220ms 卡片悬浮抬升；尊重 `prefers-reduced-motion`。

## 六、信息架构（7 模块工作流）

```
导入 CSV → ① 账户总览 → ② 关键词四象限 → ③ 转化词追踪
        → ④ 搜索词匹配度 → ⑤ 创意诊断 → ⑥ 地域效率 → ⑦ 操作清单
```
每个分析页右上角均提供「🤖 AI 解读本模块」，总览额外提供「AI 综合诊断」。

## 七、响应式

- ≥1100px：KPI 6 列 / 4 列网格完整呈现。
- 820–1100px：KPI 降为 3 列。
- ≤900px：侧边栏转为顶部横向滚动导航，主题切换保留在顶栏，内容单列。

## 八、双主题实现

- `<html data-theme="light|dark">` 切换，所有颜色经 CSS 变量派生。
- `applyTheme()` 读取/写入 `localStorage`，`toggleTheme()` 切换并重绘 canvas 图表（图表颜色经 `getComputedStyle` 取 `--chart-*` / `--geo-*` / `--heat-*` 变量）。
- 全部交互在浏览器本地完成，离线可用。

## 九、与上一版差异

| 维度 | 旧版 | 新版 |
|---|---|---|
| 导航 | 顶部横向 Tab | 左侧模块侧边栏 + 顶栏页面标题 |
| 主题 | 仅浅色 | 浅/深一键切换并记忆 |
| 品牌色 | 通用蓝 | 360 品牌绿 + AI 紫区分 |
| 视觉质感 | 平铺卡片 | token 化、阴影分层、悬浮微交互 |
| 图表 | 硬编码浅色 | CSS 变量驱动，深色同步 |
| 可达性 | 基础 | 焦点环、对比度、reduced-motion 全面覆盖 |
