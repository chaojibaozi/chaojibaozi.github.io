# 项目长期记忆：360效果评估分析系统

## 项目定位
用户（360搜索推广优化师，客户为"xc捷配信息"PCB打样行业）需要一套本地离线的推广效果评估系统：拖入点睛平台导出的CSV报告即自动按固定工作流分析并给出操作建议。

## 已确认的用户偏好
- 单HTML文件形态（index.html 双击即用，数据不出本机）
- 历史周期存 localStorage，自动跨周期环比（转化词新增/流失/上升/下降）
- 诊断阈值走可配置参数面板，目标CPA默认按当期数据自动测算
- DeepSeek API：全局综合诊断 + 每个模块单独AI解读，Key存本机

## 数据源格式（360点睛导出CSV，UTF-8 BOM，日期为 ="YYYY-MM-DD"）
- 搜索词报告：分日，含 关键词/搜索词/触发模式/转化数（唯一含转化的报告）
- 地域分析报告：仅周期汇总，无转化列
- 基础创意报告：分日，含创意标题，无转化列
- 高级创意报告：分日，仅到推广组粒度，无标题列
