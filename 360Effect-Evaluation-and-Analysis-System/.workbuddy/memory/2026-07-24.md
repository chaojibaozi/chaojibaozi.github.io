## 新增模块：⑦ CPA 基准归因（Senior Developer 吴八哥）
- 用户需求：以"转化成本低的某几天"为基准，全局分析 关键词/搜索词/创意/高级样式 各维度在哪些日期 CPA 波动大、哪些东西改变、可能由什么因素导致，深入挖掘优化系统。
- 方法论（固化进 analyzeCpaAttribution()，挂 runAnalysis）：
  1. 基准 CPA = 有转化日度 CPA 的**中位数**（抗极端值）；CPA≤基准的日期=基准日；CPA>基准×(1+阈值) 的日期=高异动日（阈值默认50%，新增设置项 cpaHighThresh）
  2. 每个高异动日按"超额成本"归因：关键词零转化当日花费=全额浪费；有转化词=(当日花费−转化×该词基准CPA)；按贡献排序得 culprit 清单
  3. 搜索词层：检测"仅在高异动日出现、基准日无、且零转化"的新增词（预算吞噬源）+ CPA 较基准骤升的词
  4. 创意/高级样式层：因 360 导出报告**无转化列**，采用 CTR/CPC 日度波动**代理归因**（CTR下滑>15%→点击变贵），界面与导出均明确标注※代理说明；地域报告仅周期汇总无分日，不参与日度归因
  5. 生成因素假设文本（逐日）+ 操作清单新增 P1[CPA归因] 动作
- 界面：part2 新增侧边栏 tab p-cpa(⑦) + panel（KPI/chartCpa 高清柱图+虚线基准/异动归因卡/关键词×日CPA异常矩阵热力/搜索词新增骤变/创意与高级样式CTR波动表）；part5 新增 renderCpa()/drawCpaChart()，接入 renderAll 与 redrawActiveCharts（主题切换/缩放重绘）；part6 新增 digestCpa + AI 模块('cpa')；操作清单重编号为⑧。
- 验证数据：基准CPA ¥123.6（基准日07-17/19/21）；高异动日 07-22 CPA ¥716.5（超基准480%，超额¥592.9），主因「捷配pcb下单」当日¥212零转化；新增无转化搜索词18个；创意/高级样式CTR异动 2/10 条。
- 校验：node --check 四JS全过；test_harness 扩展验证 R.cpa 结构 TEST_PASS；富 DOM 桩模拟 renderCpa+drawCpaChart 无运行时异常；结构校验 17 项 OK；合并 index.html 约 119KB。
