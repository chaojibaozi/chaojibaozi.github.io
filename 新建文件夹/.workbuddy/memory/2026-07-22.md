## 功能
- 拖入 xlsx/xls/csv（原生 CSV 解析 + SheetJS 读 xlsx），自动识别关键词列/表头。
- 多层规则+词典分类：品牌/竞品/产品/属性/疑问/口碑/地域/活动/人群/通用；输出分类+置信度+命中规则。
- 自适应：自动从文档抽取高频产品候选词（freq>=3）增强产品识别；仅展示命中类目（可切换）。
- 分布条形图 + 结果表（分类彩色标签/置信度/规则/来源），支持搜索、按分类筛选、点击图例联动。
- 设置抽屉：置信度阈值（低于标「需复核」）、自定义品牌/竞品/产品/地域词典与各类扩展词、重置内置。
- 导出：仅 Excel(.xlsx)，保留原列 + 分类/置信度/命中规则/来源。
- AI 增强：可选 DeepSeek 兼容接口（BaseURL/Key/Model），批量零样本分类覆盖离线结果。

## 关键坑（已修复）
1. 「测评/评测」只放口碑词，勿放疑问词（否则疑问分虚高）。
2. 拉丁品牌与中文词典品牌用 `Math.max` 而非累加，避免品牌分翻倍压过口碑/疑问。
3. 单字母尺码(L/M/S/X)会从拉丁词误触发属性，已从属性词典移除，仅保留 XL/XXL/XS 等。
4. 人群词需补「老年人/老年/男童/女童」等，否则「老年人手机」「童装男童」误归产品/通用。

## 重大优化：解决「产品词占比80%+」（同日，已联网调研 SEO 词根/搜索意图论文）
- 根因：①自学习词全部粗暴归产品；②价格词沉进产品(多少钱80<产品90)；③产品词基础分过高；④产品词不细分。
- 方法论依据：中文 SEO「词根拆分模型」(品牌+品类词根+属性+场景/人群+长尾) + Broder 搜索意图四分法(交易>信息>比较>导航)。
- 分类体系 10→13 类：产品词拆为 **核心词(core,品类词根)/型号词(model)/长尾词(longtail)**；**价格词(price)** 从属性独立。
- classify 改为「意图优先」打分(Math.max 不累加)：价格强122>疑问120>口碑116>活动114>地域108>人群104>价格弱96>属性92>品牌/竞品90>型号100(注:型号高于品牌)>核心60/长尾58>通用12。修饰词全面高于产品词，产品仅在无修饰时命中。
- 产品细分规则：MODEL_RE(字母+数字/Pro/Max/代/系列)→型号词；prodTerm 命中且(单段且额外≤2字)→核心词，否则→长尾词。
- learnFromDoc 改为抽取「品类词根」(buildModifierVocab 排除所有修饰词典)，门槛 max(3, 2%*行数) 降噪。
- BASE 新增 priceStrong/priceSoft；attribute 移除价格词、补功能规格词(变频/静音/一级能效/无线等)且颜色改「红色」防误伤「红米」；question 去「多少/几」；product 补扫地机器人/破壁机等家电。
- 设置抽屉新增「价格/交易词」扩展框；state.dict.ext 加 price；fill/read/reset 同步。
- 验证：56 词多品类样本(模拟单一品类堆积)，产品类合计 28.6%(旧 80%+)，13 类分布均衡；36 条断言全过；XLSX 读/分类/导出端到端通过。
